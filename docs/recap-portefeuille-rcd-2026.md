7. Synthèse
• Portefeuille en RC Décennale pour un montant de prime annuelle 2026 de 998 908 €.

• Le fractionnement trimestriel domine le portefeuille (50 contrats sur 71), avec un taux de règlement de 52,5 % ; le
fractionnement annuel est intégralement soldé (100 %).
